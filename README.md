# prompt2claudevideo

Skill/workflow Claude untuk menukar prompt teks kepada video.

## Guna

1. Buka repo ini dalam Claude Code.
2. Pasang HyperFrames: `npx skills add heygen-com/hyperframes`
3. Taip prompt, contoh: "Buat video 15s 9:16 promosi kelas coding untuk kanak-kanak."
